PROJECT CONTEXT & SPECIFICATION
Project Name: Halo-1
Type: Windows System Topbar & App Dock Overlay
License: MIT/Apache-2.0
Goal: Create a minimalist, macOS/Linux-inspired system bar that safely overlays Windows without replacing explorer.exe

TECH STACK
Backend: Rust (Tauri v2)
Frontend: Vue 3 + TypeScript + Composition API
Styling: CSS3 with custom properties, backdrop-filter, transitions
Build System: Cargo + Tauri CLI
State Management: Pinia (Vue)
System APIs: windows-rs crate, arboard (clipboard), sysinfo (system stats)

DESIGN REFERENCE
Dark themed topbar (similar to attached image) showing:
Left: App launcher, workspace indicators
Center: Dynamic "pill" with date/time, media controls, morphing capabilities
Right: System stats (CPU %, RAM %, Battery %, Network, Volume, Notifications)
Bottom: Auto-hide app dock with smooth animations

ARCHITECTURE CONSTRAINTS
NEVER replace or inject into explorer.exe
Run as always-on-top borderless window
Use Windows App SDK / WinRT APIs where available
Config stored in %APPDATA%/halo-1/config.json
Graceful fallback if APIs unavailable
Multi-monitor support
DPI-aware rendering

# Halo-1

A minimalist, macOS-inspired system topbar and app dock for Windows. Built with Rust + Tauri + Vue 3.

![Halo-1 Screenshot](./screenshot.png)

## Features

- **System Stats**: Real-time CPU, RAM, battery, network, and volume monitoring
- **Dynamic Pill**: Morphing center component with date/time, media controls, and clipboard
- **App Dock**: Auto-hiding bottom dock with magnification and drag-to-reorder
- **Workspace Switcher**: Virtual desktop integration with quick switching
- **Notification Center**: Custom notification management with Do Not Disturb
- **Clipboard Manager**: History of last 20 items with quick paste
- **Keyboard Shortcuts**: Fully customizable keybindings
- **Safe**: Runs as overlay, never replaces explorer.exe

## Installation

### From Releases (Recommended)
1. Download the latest `.msix` or `.exe` from [Releases](https://github.com/yourusername/halo-1/releases)
2. Run the installer
3. Launch Halo-1 from Start Menu
